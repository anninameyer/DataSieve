## Explicit trade-offs and remaining checks

The researcher-requested UI updates additionally provide a minimal icon/name logo without a tagline, no technical architecture badge, creator credit, concise worked methods, normal-scaling explanation, citation/Zenodo guidance, color-vision-friendly customizable figures, PNG/TIFF/PDF/SVG plus captions, and CSV/TSV/Excel selection. Figures and their embedded metadata/filenames contain no software branding; citations remain in the separate caption/report. Color pickers and editable hex codes update line and observation colors, with consistent median/mean visibility across plots. Horizontal grid visibility is selectable and preserved in exports. New automated tests independently reopen Excel workbooks, verify figure headers/resolution/pixels, and exercise all formats both online and in a disconnected offline browser. PDF uses a lossless raster; SVG supplies editable vectors. Publication identity and ORCID are recorded as Annina R. Meyer, https://orcid.org/0009-0006-3110-6598. The archived v1.0.0 release is cited with DOI https://doi.org/10.5281/zenodo.23540904 and the title “DataSieve: numerical data exploration and outlier review”; privacy is described in the abstract.

- Ambiguous numeric commas require an explicit delimiter choice. Unknown header names remain data until headers are selected. Thousands grouping is unsupported. Precision diagnostics disclose long numbers/safe-integer limits and preserve original text.
- Zero MAD disables modified Z for every observation. Unrepresentable derived statistics/checks are unavailable with warnings; sample SD requires two valid observations.
- Double precision; explicit limits of 50,000 records / 5 million characters. Unsupported extreme plot scales display rescaling guidance while data/statistics remain available.
- CSV formula protection prefixes dangerous text with an apostrophe. Spreadsheet programs can independently change zero-prefixed identifiers or precision; import original columns as Text.
- Browser/OS clipboard, downloads, extensions, and session restoration are outside application control. DataSieve stores no research data and resets on refresh/clear.
- The repository owner has confirmed that the Pages deployment works. Automated browser verification covers Chromium; Firefox/Safari compatibility, screen-reader review, and formal accessibility certification remain unverified.
